# Darragh Casey

I build data systems and backend services, mostly in Python and Java. My recent work covers recommender systems, NLP pipelines and statistical analysis.

## Projects

**[News Aggregator](https://github.com/dc-171/news-aggregator-backend)** ([frontend](https://github.com/dc-171/news-aggregator-frontend))
My final-year project at University College Dublin. It clusters coverage from 20 outlets into stories, summarises the left, centre and right viewpoints, and personalises the feed with a hybrid recommender.
Python, FastAPI, PostgreSQL, pgvector, HDBSCAN, React

**[Guitar Marketplace](https://github.com/dc-171/guitar-marketplace)**
An event-driven microservices marketplace with auctions, built in a team of three. I built the user, auction and gateway services.
Java, Spring Boot, RabbitMQ, PostgreSQL, Docker, React
